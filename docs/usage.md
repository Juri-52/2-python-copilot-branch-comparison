# 基本の操作

main.pyがあるフォルダーで起動します。メニューで1を入力すると、JSONに記録された順番で商品一覧を表示します。2を入力すると、分類別の在庫レポートと全体の合計を表示します。0で終了します。それ以外の入力では案内を表示し、メニューへ戻ります。

レポートは文房具、飲料、日用品、全体の順に表示します。各行には商品種類数、在庫の総数、在庫金額が表示されます。

一覧の1行目は次のようになります。

```text
1 | ノート | 文房具 | 250円 | 在庫 8個
```

商品一覧を開く操作では、JSONの内容を保存し直しません。プログラムを終了して再起動しても、配布データが変わらないことを確認します。
