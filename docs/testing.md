# 動作の確認

main.pyがあるフォルダーで、仮想環境のPythonを使います。

```bash
python -m pytest -q
```

Productの表示、JSONの読み込み、一覧の順番、一覧のコピー、商品がない場合に加えて、少数の商品による分類別集計と空の商品一覧のレポートを確認します。

## 新しい機能を追加するとき

新しい条件に合うテストを追加します。既存テストの期待値を、誤った実装に合わせて書き換えないでください。pytestの結果と、メニューから操作した結果の両方を確認します。料金や在庫数はdocs/data.mdと比較します。

## 手動で確認する項目

- 1で商品10件を表示できる。
- 2で文房具、飲料、日用品、全体の順にレポートを表示できる。
- 配布データで分類別の値が文房具4種類14個2620円、飲料3種類10個1620円、日用品3種類14個4250円、全体10種類38個8490円になる。
- 繰り返し1を選んでも、件数と順番が変わらない。
- 0で終了できる。
- メニューにない値を入力しても、案内の後に続けて操作できる。
- 作業後にdata/products.jsonの差分がない。
