# 在庫レポートの要件
全体をすぐ把握できる簡単な表示と、分類別に詳しく確認できる表示をそれぞれ作成し、実際に動かして比較する

## このブランチで作る案
分類別に詳しく確認できる表示

## 表示する項目
- 分類 - 商品の分類
- 商品種類数 - JSON件数（stockが0のものも含む）
- 在庫の総数 - stock合計
- 在庫金額 - 各商品のprice*stockの合計

## 集計する方法と単位
分類別に集計し、最後に全体も集計する
- 商品種類数 - 種類
- 在庫の総数 - 個
- 在庫金額 - 円

## メニューと表示順
文房具、飲料、日用品、全体の順に表示する

## 空の一覧の場合
0を返す

## 確認例
・商品が存在する場合
分類	商品種類数	在庫の総数	在庫金額
文房具	4種類	14個	2620円
飲料	3種類	10個	1620円
日用品	3種類	14個	4250円
全体	10種類	38個	8490円

・商品が存在しない場合

分類	商品種類数	在庫の総数	在庫金額
全体　0種類　0個　0円
